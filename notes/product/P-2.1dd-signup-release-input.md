## Contract

The actual default Worker fetch path remains closed unless `FOLLOW_SIGNUP_ENABLED` is exactly `"1"` and `FOLLOW_SIGNUP_RELEASE` is a valid deployment-supplied JSON string. The existing injected `followSignupRelease` supplier takes precedence and its implementation is unchanged. Missing or malformed descriptor returns the existing 404 without consuming the body, catalog or database. Existing method, Origin, content-type and body-slot checks precede descriptor preparation.

The exact descriptor fields are `version`, `origin`, `dailyLimit`, `deadlineMs`, `maxBytes`, `maxKeys`, `release` and `predecessor`. Version is the number 1, origin is exactly `https://internscout.org`, and limits are explicit positive safe integers. No production values or defaults are selected. The UTF-8 descriptor ceiling is 4,096 bytes, checked after a cheap JS-length bound and before JSON parsing. Duplicate decoded object names, including escaped aliases, reject.

`release` retains the existing exact fields `url`, `sourceSha256`, `catalogSha256`, `notBefore` and `expiresAt`. Times are epoch milliseconds. `predecessor` is either exactly `{ "genesis": true }` or exactly `{ "url": ..., "sourceSha256": ..., "catalogSha256": ... }`. Null, absent predecessor, failed retrieval and process restart cannot imply genesis. Both targets must be canonical HTTPS URLs on the exact approved origin, without credentials, query or fragment. Non-genesis targets must be distinct. Identical digests at distinct targets remain allowed for an unchanged release renewal only when the operator independently verifies the predecessor. The descriptor cannot prove that provenance; copying proposed current bytes into another URL does not establish a predecessor. Digest inequality would not establish that authority either.

All input is parsed and privately snapshotted synchronously before body consumption. The existing async `loadCatalog` seam then reads the pinned predecessor and current catalog sequentially within the same four request slots. The unchanged loader enforces exact response URL/status, no redirected fetch, fatal UTF-8, canonical JSON, source/catalog digests, byte/key bounds and cancellation. The predecessor's exact canonical bytes are structurally parsed with empty prior sets, solely to obtain the independently approved continuity root's `valid` sets. This is not a genesis claim or a recursive proof of its publication history. Its read uses the CURRENT descriptor's authority interval, not renewed historical signup authority. Only the current catalog's `signup` sets may admit a request, and all predecessor valid keys must survive in current `valid`.

There is one catalog-operation deadline, starting when loading begins after body/session checks. Each existing loader receives only the rounded-up remaining milliseconds. Remaining time uses the greater of nondecreasing wall elapsed and monotonic elapsed, with exact checks after each result. Each phase retains its own abort/cancellation ownership. A stalled or noncooperative late response cannot trigger another phase or database admission. Async/rejecting clock samples are invalid and their rejections are consumed without awaiting them. The existing separate five-second request-body bound is unchanged.

`maxBytes` is a **per-catalog** bound, capped at 1,000,000 bytes; therefore non-genesis consumes at most 2,000,000 wire bytes and genesis at most 1,000,000. `maxKeys` retains the parser's per-array/alias bound, capped at 10,000. These are technical ceilings, not deployed settings or total heap estimates. Existing exact #510 evidence measured 148,454 bytes, 2,201 company keys, 66 fields and 65 states. The prior real-export qualification already exercised explicit 1,000,000-byte/10,000-key bounds. The new synthetic scale case matches the 2,201-company count and checks descriptor fit. No catalog key sets are put into a small environment variable.

The existing route still checks current pin/session time after reads and through hashing/rate work. Its unchanged 0025 first-statement SQL guard rejects expired catalog authority before either queue batch mutates. A previously admitted database operation is not canceled by this network deadline. Existing generic linked-session outcomes are preserved: a removed session cannot queue a link, even where the response deliberately remains generic 202.
