# P-2.1dl staged Follow site publication

[#617](https://github.com/bpmcginley/InternshipFinder/pull/617) is a dormant Python-only adapter on frozen [#598](https://github.com/bpmcginley/InternshipFinder/pull/598), normally integrated with main `efc42c5c`. It has no Pages option, environment setting, route or provider call. It does not enable Follow or employer browser capture.

`publish_follow_site` returns without inspecting inputs unless `enabled is True`. The caller supplies a stable regular source tree, absent private output directory, exact same-export source and preview pins, catalog continuity or explicit synthetic genesis, all existing planner bounds, current App/source hashes, retained wrappers and site bounds. The site entry bound counts directories as well as files using streamed traversal. Optional sitemap/noindex files are validated regular bounded read inputs and resolved to absolute paths before invoking the internal publisher. Owned output components must use exact case, including on Windows. Existing generated assets are accepted only with identical bytes. The catalog output path is explicit. No production URL, genesis, freshness authority or retention policy is chosen here.

The adapter captures the original selected export once, verifies its staged copy, and derives both annotations from those raw bytes. The actual loader and employer selector build the complete model batch. Every model and immutable asset must pass the existing planner before any generated artifact is written. Rendering then uses the exact immutable wrapper. A private sibling tree receives the paired shards, preview, catalogs, graph assets and normal generated pages. A late failure removes that private tree. Successful publication uses an atomic absent-target rename, with Windows and Linux implementations. Unsupported platforms fail closed. Existing source and prior output directories remain unchanged.

Retained wrappers require their exact reviewed standalone source, hash, App generation and body. Every supplied generation is fingerprinted and checked for complete module references. Every wrapper already in the source must be acknowledged and match. The adapter retains them all, without aging or deleting assets. A previous whole output directory remains the rollback artifact. This proves local artifact preservation, not production continuity or cache lifetime.

The private context rejects placements reports and duplicate employer staging before work. It exposes no arbitrary CLI arguments or external report output. The ordinary CLI and its report behavior are unchanged. Production publication still requires its separate allowlist/workflow and authority integration after G3. Advisor subscription, provider and privacy activation remain separately held.
