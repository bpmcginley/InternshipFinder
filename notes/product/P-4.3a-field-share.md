# P-4.3a Multi-field share and reload

Claimed from `8a8fbe744947cc521862db389018abb379775a80`. Refactor lead released the native Core and golden scope for this package.

A normal share serializes seven selected fields, but native Core restores only six. This package will preserve every supported selected field, deduplicate in first-selection order, and reject unsupported or oversized input without changing other URL filters.

Owned paths: `docs/js/core/profile.mjs`, a new focused site test, this note, the P-4.3a tracker row, `notes/product/screenshots/P-4.3a/`, and both coordinated golden artifacts. Retained classic scripts, providers, data collection and deployment are outside scope. Validation and exact artifact differences will be recorded before review.
