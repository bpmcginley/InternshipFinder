No provider, real account or payment is contacted. `results.json` records zero external requests and no page errors.

Before uses the exact three native modules from #429 `9de5b9848e65351d73d8d5198125aac07f4ac1b6`; after uses this package. Other assets and the public synthetic listing fixture are identical. Escape closes Account and returns focus to its button. No horizontal overflow was observed.

The ordinary root-page scenario has no payment return marker. It verifies a new authenticated read on return, one read for paired persisted-pageshow/visibility events, omission after the fresh response removes purchased units, omission after failure, and recovery on the next return. The browser executes actual UI code with synthetic lifecycle events; this is not proof of real BFCache storage or payment completion. Unit tests additionally cover in-flight coalescing, an initially hidden page, cleanup, malformed optional fields, both purchased-creation compatibility modes, auth A-B-A generations and superseded errors. No screen-reader execution is claimed; live-region semantics are checked in source/DOM tests.
