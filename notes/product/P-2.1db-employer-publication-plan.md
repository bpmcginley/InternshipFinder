# P-2.1db dormant employer Follow publication plan

This is a pure, default-off in-memory planner on reviewed #594 `603b012d71bc944bb93b94cfa46a52107a7de432`. Only the new planner, its tests and this note are owned. No shared publisher/runtime/asset graph, workflow, allowlist or STATUS edits. No filesystem writes, public copy/configuration, publication or activation.

`plan_employer_follow_publication` requires literal `enabled=True`. Otherwise it returns `None` without inspecting any input, leaving the caller's default artifacts untouched. Enabled callers supply the already validated paired stage, actual same-export organic loader rows, a bounded nonempty list of employer models, explicit positive row/source/model/asset bounds, the existing `core_graph.plan(APP)` result, an independently trusted current App digest, and approved standalone bytes with their expected source digest. This is a trusted internal handoff, not release authentication or a reader of request-supplied configuration.

Before copying the graph, its file count and body byte total are bounded; path lengths are bounded too. Every included generation must have safe flat paths, complete reachable sibling imports, an entry, and its exact existing `core_graph` fingerprint. The entry must identify the explicit current generation, even when older retained generations are present. Both dependency files and the exact reviewed helper declarations must be present. These declaration checks supplement the trusted source pin; they are not a general JavaScript parser or permission to use unreviewed code.

The planner accepts precisely the reviewed standalone's two static imports, with its independent source digest, and rewrites only those imports to `follow-form.mjs` and `follow.mjs` in the current immutable App generation. It rejects raw/mixed/historical targets, query/fragment aliases, entry boot imports, dynamic or extra imports and invalid UTF-8. Rewritten bytes are hashed into a separate `js/follow-company-modules/<sha256>.mjs` asset. This path is a staged asset proposal, not an allowlist or public release change. The resulting mapping contains the supplied graph generations plus that immutable module; bytes and mapping are immutable.

All models then pass #594's same-export selection before any plan is returned. Duplicate paths, late invalid models, stale membership or catalog pins, and the inherited renderer's multibyte text limit fail the whole batch without changing caller rows/models. Label, spelling and selection logic are reused unchanged. The plan preserves both original stage receipts and returns selected model copies, assets, exact script URL, current graph digest and assembled-module digest. No result is returned on partial failure.

## Qualification

`python -m pytest backend/tests/test_follow_employer_publication.py backend/tests/test_follow_employer_selection.py -q -p no:cacheprovider` passed **77 cases** (32 planner, 45 selection), with bytecode disabled and Node **22.23.4** for the native ESM case. Pinned Ruff lint/format and diff checks pass. Tests use the actual checked-in App graph through `core_graph.plan`, real paired-stage/source/model fixtures and the real employer renderer. Default model bytes stay unchanged; optional rendering adds only #575's exact existing control. Only two import references change in the standalone module.

Native Node ESM links and evaluates two independently assembled generations, each resolving exactly the standalone and its two dependencies. No dashboard entry boots; the isolated context provides no browser, fetch or network port. Combining the two returned asset plans keeps old and new references disjoint and resolvable. This is a synthetic cached-generation qualification, not a browser test or implemented history-retention policy. A genuine catalog-valid multibyte alias above the inherited renderer limit rejects before a plan is returned. Bounds, missing/changed graph files, unavailable exports, stale current pins, malformed imports and late model failures are covered.

The existing #594 retained-export replay remains the model/data evidence; this package adds no new full-export or public-artifact claim. No golden outputs, screenshots, provider settings or live data were changed.

## Remaining boundary

The future publisher must bind acquisition/freshness/prior continuity, use these same captured rows and receipts, preflight its complete eligible model set before any writes, and replace the renderer's raw script URL with the returned immutable URL. The current renderer still emits its reviewed raw URL. This package does not write or select a catalog destination, change the publisher, or make failed filesystem writes atomic.

Old assembled modules and their corresponding App generations must be retained across fresh publication and rollback; this planner does not retrieve that history. Existing graph retention alone does not retain these new assembled modules. Cached older shared modules missing helper exports are ineligible. Publisher/Advisor ownership, asset allowlisting, coordinated graph/history integration, trusted catalog delivery, sender qualification and G3 remain gates. No production switch or activation is introduced.
