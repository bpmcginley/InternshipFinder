# P-2.1ao bounded R2 slot qualification

[Draft #468](https://github.com/bpmcginley/InternshipFinder/pull/468) starts on exact #450 `5eff127f49b78329a679a833b2509cfc9aecd61c`. This is a dormant storage primitive for the proposed design, not a selected or activated storage system. Own the new adapter, two registered tests, this note and two tracker rows. No existing runtime caller, control SQLite, expiry policy, route, private host, bucket binding, deployment or public artifact changes.

`createFollowCheckpointR2Slots(bucket, {maxPayloadBytes, maxEnvelopeBytes})` accepts only slot 0 or 1, mapped to two fixed keys. Both limits are required safe integers; the envelope budget must allow the payload budget plus the bounded header. `prepare(Uint8Array)` copies caller-owned canonical bytes before awaiting SHA-256 and returns an opaque immutable receipt containing kind, nonce, digest and byte count. `tombstone()` prepares an empty-body receipt with a fresh nonce. The binary envelope is a canonical versioned JSON header, LF, then exact payload bytes. A cryptographically random 128-bit nonce is in the actual object body on every preparation, including tombstones; it is outside the payload digest. This module does not parse or reconstruct #365/#372 canonical checkpoint formats.

The future control authority must durably reserve the exact nonce/digest before PUT. `write(slot, expectedEtag, receipt)` conditionally creates with If-None-Match when expectedEtag is null, or replaces only the exact existing ETag. It consumes that prepared envelope once, never retries and never deletes the fencing key. A successful acknowledgement is followed by bounded readback and exact ETag/nonce/digest/kind verification. Only then does it report stored. A competing write reports conflict; an exception, malformed acknowledgement or unverifiable readback reports uncertain with no raw storage details. An explicit cold read permits recovery against the previously durable reservation after a lost acknowledgement. Missing is observational only, never proof that an uncertain write cannot still arrive. Tombstones use the same conditional path; authorization to clean a retired generation remains entirely outside this adapter.

Reads reject oversized metadata before reading chunks, enforce the exact declared object size while streaming, bound the header and payload, reject malformed/extra/noncanonical headers and verify SHA-256. A rejected body is cancelled. All returned payloads are byte copies. Caller byte limits bound materialization; storage-I/O deadlines and fresh control-clock admission are not supplied here. A stalled operation cannot be treated as failed or authorize a competing generation. Readback proves only the observed slot identity, not current control revision, active lifetime, retention compliance or visibility permission.

Validation: all 752 registered Node tests pass on Node 22.23.4, including five synthetic adapter tests and one actual local workerd R2 qualification. The native test uses a new temporary test-only config with `getPlatformProxy({persist:false, remoteBindings:false, envFiles:[]})`, disables auxiliary CF metadata retrieval and disposes its isolated storage. Both 2,540,000-byte synthetic payloads round-trip exactly. Conditional tombstone initialization and replacement work; two same-precondition writers produce one stored winner and one conflict. Identical payload bytes with a fresh body nonce yield a different ETag. Old cleanup and create-if-absent cannot replace an occupied generation. A committed PUT with a lost reply is recovered only by exact cold nonce/digest/payload readback, followed by conditional tombstoning; both fixed keys remain. Native oversized and malformed objects fail closed. Synthetic tests also cover caller mutation, invalid bounds/slots/forged receipts, one-attempt receipts, truncated/corrupt streams, cancellation, unknown headers and unavailable readback. Local Windows workerd uses the existing pinned 1.20260911.1 binary through a dependency lookup fallback. ESLint, Prettier and diff checks pass. No live bucket or provider request was used.

The storage decision, physical replacement lag, provider recovery/backup behavior, SQLite recoverable metadata and non-rollback witness remain open under #450. This package does not qualify retention cutoffs, promotion, reservation CAS, late-write visibility, controlled restore or automatic rollback detection. Those require the separate control authority and owner qualification; the ability to conditionally replace R2 bytes does not resolve them. Independent exact review and hosted CI are required. Keep draft needs-bruce; no activation.

Independent review reproduced that Node Buffer.slice shares memory. The adapter now uses an intrinsic independent Uint8Array copy before the first await. Both the synthetic regression and the actual local workerd R2 case mutate Buffer input during prepare and again before write, then verify the original SHA-256 and stored bytes. Both failed before the correction and pass afterward; all six focused tests and the full 752-test Node registry pass. No other runtime behavior changes.
