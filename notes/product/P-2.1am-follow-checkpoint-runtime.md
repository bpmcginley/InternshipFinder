# P-2.1am Separate private follow checkpoint Worker

The isolated entry reuses the reviewed #444 checkpoint handler and SQLite Durable Object. It accepts requests at one exact, configured HTTPS DNS origin. A stable internal name selects the singleton independently of request headers. The entry fails closed when required settings are missing or invalid, and the handler authenticates the writer or recovery operator before body reads or store access.

The detached config is `worker/wrangler.follow-checkpoint.toml`. It defines the SQLite class and binding and disables workers.dev, version previews, logs and Logpush. It includes no route, account, origin, byte setting or credential. A future operator must provide a canonical origin such as the shape `https://checkpoint.example.test` without a trailing slash, `FOLLOW_CHECKPOINT_MAX_BYTES` as canonical positive decimal text within the handler's bound, and distinct `FOLLOW_CHECKPOINT_WRITER_SHA256` and `FOLLOW_CHECKPOINT_OPERATOR_SHA256` digests. Set the origin through `FOLLOW_CHECKPOINT_ORIGIN`. Keep the worker name, SQLite class and singleton stable across approved updates.

Run the local test with `node node_modules/vitest/vitest.mjs run --config vitest.follow-checkpoint-runtime.config.js` from `worker/`. It loads the actual detached Wrangler config with synthetic settings and remote bindings disabled. It verifies exact-origin routing, a stable SQLite singleton shared across authorized roles, and fail-closed behavior before request-body access.

Activation still needs an approved private hostname and ingress policy, an exact alias/bypass check, credential custody and rotation, verified bindings and a decision on SQLite's 30-day point-in-time recovery history. The public Worker and G3 writer remain outside this package. No deployment or provider request was made. See [Wrangler configuration](https://developers.cloudflare.com/workers/wrangler/configuration/), [version URLs](https://developers.cloudflare.com/workers/versions-and-deployments/version-urls/) and [SQLite storage](https://developers.cloudflare.com/durable-objects/api/sqlite-storage-api/).
