## Optional model and source boundary

`with_company_follow(Page, aliases=..., companies=...)` accepts the trusted current alias map and signup-company set from the same original export/catalog used by [#510](https://github.com/bpmcginley/InternshipFinder/pull/510) and [#570](https://github.com/bpmcginley/InternshipFinder/pull/570). The caller owns capture, pins, validity and coordinated publication; this helper performs no I/O or independent provenance verification. Every open model row must have its exact listing ID, public name and dedicated `follow_company_key`; all model spellings/names must map to that one current signup key. Missing, mixed, unknown, duplicate, closed and retained-only identities reject. No slug, label normalization or employer-counter key is used. Immutable selected identities and the exact approved spellings tuple are rechecked by the renderer, rejecting later row/name/key changes.

The existing employer renderer return type is unchanged. With selection omitted, every employer page remains byte-identical, without control, module reference or request. An enabled model emits one escaped empty section and first-party module reference ahead of the existing listing actions. Thin/noindex pages use the same validated optional model; robots directives remain unchanged. Redirect and other default pages remain unchanged. No runtime/catalog/publisher or Advisor path wires this option.

## First-party browser adapter

`docs/js/follow-company.mjs` mounts only explicit employer markup. It imports existing `followSelection`, the narrowly exported approved copy/email validator, and the existing bounded request helper. It loads no React or third-party asset. Shared React form behavior and copy remain unchanged. The adapter performs no auth or storage reads and always submits `link:false`; account linking is not offered on this surface.

All DOM controls are constructed with text nodes and exposed only after event/lifecycle handlers are installed. Module failure, older cached shared exports or initialization failure leaves no input/submit surface, preventing native GET email submission. A valid control opens only by explicit user action, focuses Email, uses 44px controls, live/focusable generic status and Escape dismissal. Busy Escape preserves the one current request. Pagehide, removal or changed selection aborts and clears input; stale results cannot display success. Request timeout, empty-202 contract, no credentials/referrer/cache/redirect/retry and body-only anonymous scope reuse the reviewed transport.

Raw standalone imports are not transitively version-stamped. Before activation, verify the exact new module plus matching shared form/request dependencies are delivered coherently; the native older-export test qualifies fail-closed behavior, not deployment cache policy. The static source introduces no release flag or guessed catalog URL.
