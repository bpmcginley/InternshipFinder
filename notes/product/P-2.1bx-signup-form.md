PR [#533](https://github.com/bpmcginley/InternshipFinder/pull/533), based on `ce6f040a`. Owner: audit_worker_extension. Source only, default off and unmounted. No email, Worker request, browser storage, account lookup or production setting changes.

## Boundary

`createFollowForm` takes the existing native React hooks and `h`. The returned component renders nothing unless `enabled === true`. A future reviewed mounting layer supplies one immutable catalog selection, current sign-in state, a session generation that changes on every account/auth change, and a stable bounded request callback. Company selections contain a public key and label. Search selections contain field/state key-label pairs. Only keys, normalized email and explicit `link` enter the callback. No other dashboard filters are copied. Trusted labels are rendered as text.

The callback receives `{email, link, scope}` and `{signal}`. Only `{status: "accepted"}` yields the generic accepted message. All other outcomes and thrown errors use the approved unavailable message. The callback owns request deadlines, current authorization and HTTP status mapping. This component adds no transport. It admits one request at a time. A new scope, sign-in state, session generation or disabled/unmounted component aborts its signal and discards late UI results. Abort does not promise server cancellation. Explicit consent starts unchecked and is cleared after acceptance, dismissal or identity/scope changes. Request and email state exist only in component memory.

The file is outside `docs/js/app/`: the existing graph rejects unreachable modules, and importing it would change the loaded dashboard graph. No app assembly, index HTML, stylesheet or graph validator changed. The exact allowlist entry permits this static file only. Measured actual golden output adds only `js/follow-form.mjs`: all 836 previous artifact bytes, including App/Core generations and dashboard, remain identical. Updated manifest and archive contain 837 files.
