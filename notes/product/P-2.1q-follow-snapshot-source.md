# P-2.1q dormant follow snapshot source adapter

[PR #320](https://github.com/bpmcginley/InternshipFinder/pull/320) is based on exact ready #315 `8228a864`. Needs Bruce. This adapter reads only bytes supplied by its caller.

The trusted capture owner supplies an independently established exact export timestamp, an aligned authoritative lower bound, a complete-capture assertion, and SHA-256 of the exact index and every expected slim shard. The current export index has no shard digests. Matching names and counts alone would not rule out same-count bytes from another generation. The adapter checks exact bytes, index time and file set, canonical relative filenames, actual per-shard row and open counts, and explicit total input byte and row-occurrence limits. It rejects missing or extra shards, malformed or duplicate-key JSON, duplicate IDs within one shard and conflicting facts across shards. Identical parsed rows repeated across different shards collapse to one stable listing ID. No filesystem path is opened.

The raw index timestamp must be timezone-aware and equal the trusted exact generation. Naive `first_seen` is accepted only when the capture owner explicitly attests verified legacy UTC provenance for these inputs. Missing or malformed first-seen values on open rows reject the capture. The lower bound is never inferred from time or contents. For the output, floor the authoritative upper to a completed UTC millisecond and apply the window to the original timestamps before rounding selected first-seen times up. For millisecond-aligned bounds L and U, `L < ceil_ms(t) <= U` if and only if `L < t <= U`. The fractional export tail stays outside this window and can match the next complete window. A timestamp beyond the exact export generation rejects the capture. A lower bound at or beyond the completed upper, or absent completeness proof, is an error rather than a valid empty window.

Known closed roles and roles outside the proven interval do not enter the projection. Selected public display facts, actual regions and approved field/state intersections go through the unchanged #315 producer. Remote-only geography does not create a state key. Unsupported selected rows or URLs fail the whole capture. The trusted scope catalog stays independent of the current rows.

Synthetic tests cover 33 adapter cases, including exact microsecond/millisecond endpoints, next-window carry, offset and legacy provenance, wrong generation, same-count mixed bytes, malformed inputs, duplicate/conflicting rows, cap boundaries and real empty intervals. Adapter, producer and adjacent public-data tests passed 81 with the optional exact Worker probe. A separate synthetic stdin check passed the adapter’s two consecutive windows to the #310 matcher at `c09cf2816fdbbd99082aaaddfb30d4874e694a12`, proving exact expected matched IDs and matching SHA-256. Ruff and diff checks passed.

This proves completeness only relative to the trusted fixed corpus. A production capture owner still needs to establish generation, byte identity, source eligibility and legacy UTC provenance. Publication path, freshness, immutable recovery and retention, and operational limits remain pending. No export, config, Pages, public path, golden, sender, provider or deployment changed.
