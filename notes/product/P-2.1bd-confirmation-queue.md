# P-2.1bd Atomic pending Follow confirmation queue

Claim the existing Follow request storage helper, an additive 0021 migration,
its legacy schema mirror, focused native D1 and migration tests, and owned
tracker rows. The new request path saves a pending scope and queues one
confirmation job in one transaction. The seven-day scope lifetime remains the
limit. Queue rows contain only existing subscriber and scope references,
timestamps and an opaque job ID. No email is sent and no route is mounted.
