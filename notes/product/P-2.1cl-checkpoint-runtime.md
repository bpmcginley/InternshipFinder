# P-2.1cl checkpoint runtime composition

Draft [#552](https://github.com/bpmcginley/InternshipFinder/pull/552) adds `createFollowCheckpointRuntime`, a provider-neutral composition of the reviewed reservation, paired snapshot, HTTP staging and promotion helpers. It requires literal `enabled: true` and explicit qualified control, two-slot store, codec, witness supplier and bounds. Disabled construction touches no supplied dependency. Reads remain unavailable and mutations cannot proceed.

The runtime uses the control's synchronous SQLite snapshot/time capture. Each paired read pins one witness object for both authority checks. Stage retains the existing durable reservation, single-use upload and exact lost-acknowledgement readback. Promotion retains the existing predecessor, generation, checked-at, replay and atomic metadata predicates and does not issue a slot PUT. There is no new schema, retained field or retry policy.

The actual native HTTP fixture now delegates its read/stage/promotion methods to this source factory. Its wrapped slot/witness ports still inject delayed uploads, ambiguous acknowledgements and cleanup faults. Two existing probes now target the underlying source ports: reservation reconciliation for a lost final acknowledgement, and control.now for a regressing clock. Their assertions are unchanged. New native cases cover absent/off/malformed opt-in with zero dependency access, configured disabled HTTP framing with unchanged metadata/slot ETags, absent initialization, pinned witness/supplier failure and invalid bounds. Existing local SQLite/R2 suites continue to qualify stage, promotion, rollback, expiry, recovery and cleanup.

The factory has no bootstrap or physical provider fallback. Synthetic initial seeds, the fixture's older loose promotion helper, published-slot retirement/reaping and fault methods stay test-only. Initialization, qualified independent witness and physical retention/restore evidence remain release gates. The actual detached entry still exports the older raw SQLite store. No entry export, route, provider selection, binding, configuration, alarm, workflow or production activation changes. A later separately reviewed selection must supply qualified ports and the approved operational lifecycle before this runtime can be mounted.

All inputs and transport in this package's qualification are synthetic/local. No visible wording or public artifact changes. Exact test results and source identity are recorded in the PR. Independent review and owner merge remain pending.
