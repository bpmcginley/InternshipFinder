The runner verifies the independently supplied SHA-256 and requires one label for each valid company, field and state, including retained keys. It delegates label, canonical scope and URL checks to the merged presentation helper. The caller still has to obtain approved exact inputs from the same qualified export. This change creates no label artifact or deployment setting.

The runner checks rendering with synthetic credentials before ownership, then passes approved values and explicit work limits to the existing durable owner. It returns only the aggregate status. It introduces no additional owner, storage, schedule, provider settings, sender defaults or outbound call of its own. The actual entry, monitored cadence, release acquisition and live sender/provider qualification remain separate.
