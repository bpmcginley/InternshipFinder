# P-2.1bu Private Follow witness compare-and-swap

[#529](https://github.com/bpmcginley/InternshipFinder/pull/529) qualifies the core witness port used by the [checkpoint control](P-2.1bi-checkpoint-control.md) and the [witness classifier](P-2.1ap-follow-checkpoint-witness.md). The adapter reads or replaces one bounded canonical record. It accepts only the version, phase, opaque epoch, revision, transition nonce and control tokens already defined by the classifier. A separate storage tag identifies the exact version for compare-and-swap. The record contains no checkpoint body, listing identity, writer identity or user data.

The injected `readRecord` must return a strongly consistent `{tag,text}` snapshot. `compareAndSwap` must condition one replacement on the exact tag, return literal `true` only for a committed write, and never reuse a tag. The adapter also reads back the exact new record under a different tag before reporting success. Malformed, closed or unavailable authority cannot prepare or finish. `prepare` admits only the exact stable predecessor. `finish` accepts only an exact prepared transition and matching committed receipt. It never repeats a conditional write after uncertainty. An ambiguous predecessor stays closed. If the witness is already stable at the successor after a lost acknowledgement, a fresh matching read can admit access without another write.

Seven new local workerd cases use actual RPC between two separately persisted SQLite Durable Objects. They cover competing prepares, exact receipts, malformed records, lost acknowledgements, rollback detection with unchanged R2 slot identities and independent eviction of each object. The rollback case replaces the local control snapshot in the fixture; it does not call provider PITR. The cleanup check uses a synthetic cutoff and verifies that a missing cleanup journal port holds before any physical write. All 138 dedicated native integration cases and 875 Worker Node tests passed. No shared test registry, production configuration or entrypoint changed.

The cleanup journal needs an independently qualified atomic contract before this adapter can replace the full harness witness. Controlled restore also needs an external close-and-drain gate and verified fresh epoch before reopening. Provider selection, restore isolation, approved physical deletion and retention, private bindings, writer integration and activation remain held. The synthetic witness uses local SQLite solely to qualify the protocol.
