# P-2.1by Follow witness R2 port qualification

[#534](https://github.com/bpmcginley/InternshipFinder/pull/534) supplies the existing witness CAS port through one injected R2 bucket and one dedicated fixed key. The port reuses the two-slot adapter's bounded canonical envelope, SHA-256 check and one-use write receipt. The witness text is at most 2,048 ASCII bytes, and the object bound is 2,304 bytes. A new 128-bit random nonce is in each actual object body. Both payload slots retain their existing behavior.

The port requires an existing valid witness envelope and an exact unquoted current ETag. It accepts a single conditional replacement of the same record version, then requires exact nonce/digest and ETag readback under a different tag. Missing, malformed, stale or closed authority holds. The port leaves initialization, close and reopen to a future qualified operator procedure. The core [v1 witness](P-2.1bu-witness-cas.md) and [v2 cleanup journal](P-2.1bw-witness-cleanup.md) retain their transition checks.

Six local workerd cases use actual R2 for malformed and closed state, repeated identical text, conditional conflict, forged/lost acknowledgement, and v1/v2 composition with distinct payload keys. Two same-tag writers reached the binding and one won. Three replacements of identical witness text produced distinct body nonces and ETags. The six existing two-slot focused checks, 150 dedicated native integration tests and 875 Worker Node tests passed.

The local fixture directly rewrote the original object bytes outside the port and recovered the original ETag. Production qualification must keep the witness key outside the restored control's authority, restrict other writers and verify private uncached storage. The supported writer's fresh body nonce addresses ordinary repeated writes. It establishes neither absolute ETag nonreuse nor provider retention or physical deletion. Provider selection, retained metadata approval, controlled restore, production binding and activation remain held.
