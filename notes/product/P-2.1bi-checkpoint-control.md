[#513](https://github.com/bpmcginley/InternshipFinder/pull/513) starts on exact #509 `2bf857aa6bf37c41bf3f029deaaba2849f558848`. It extracts the existing native harness's SQLite control and witness transaction authority into `FollowCheckpointControl`. The harness delegates its metadata reads, fresh database UTC clock, admission, change and acknowledgement recovery to that source. Reservation, upload, reconciliation, retirement and fixture initialization remain in their existing harness methods. No production entry, legacy body store, provider binding, workflow or settings change occurs.

The source owns the existing single metadata row and SQL statements. A synchronous capture returns one transaction's raw metadata and database time. Admission requires a matching independent witness and unchanged local state across that read. A change evaluates the trusted synchronous predicate on a copy, prepares one witness successor, performs any explicitly supplied external effect, then repeats the same predicate against exact unchanged metadata and fresh SQLite UTC inside the write transaction. The new revision and receipt commit with that metadata. Each operation pins one witness object through admission, preparation, finalization and readback. Every mutation acknowledgement must be exactly true. External ports receive separate copies of the captured predecessor, successor and receipt, so they cannot change the private CAS. Witness finalization and another admitted read are required for a committed response. External I/O never occurs inside SQLite. The optional pre-commit hook is retained for native interruption/expiry qualification.

Missing initialization or witness never creates authority. A prepared predecessor cannot be automatically aborted. Recovery finalizes only the exact committed successor receipt and changes no metadata or expiry. Lost acknowledgements, rollback, mismatched receipts and unknown outcomes remain held. The source additionally rejects unsafe database time, exhausted safe-integer revisions before witness preparation, and asynchronous/non-boolean predicate acceptance and invalid non-null effect ports. Rejected asynchronous predicates are never awaited or accepted, and their possible rejection is consumed at both evaluations without writing metadata. Existing valid lifecycle behavior and the approved control fields are preserved. Raw checkpoint bodies, listing tuples and new identifiers are not added to storage. Trusted domain actions remain responsible for the reviewed metadata shape and lifecycle predicates. The source exposes no ordinary unfenced save operation.
