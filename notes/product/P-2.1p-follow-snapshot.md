# P-2.1p dormant follow snapshot producer

[PR #315](https://github.com/bpmcginley/InternshipFinder/pull/315) develops only an offline Python producer. Needs Bruce. The site build does not import it or publish its output.

`build_follow_snapshot` takes a materialized, already validated complete window of eligible public open roles. The caller supplies the authoritative upper and lower instants, explicit completeness attestation, full known company/field/state sets, and positive safe-integer byte, role, text and window bounds. The catalog must include valid scopes with zero recent roles. A row supplies only the existing stable 16-hex listing ID, aware first-seen time, open state, public display facts, posting URL and approved field/state keys. The builder derives the employer key with `site.source.employer_key`. It copies no other source fields.

All input instants must carry a timezone and align exactly to a millisecond in UTC. The builder emits `YYYY-MM-DDTHH:mm:ss.sssZ` without rounding or substituting a build clock. The eligible interval is **(covers_after, generated_at]**. Unsupported time, incomplete input, out-of-window data, duplicate IDs, bad rows and exceeded bounds raise `ValueError` before any output is returned. A proven complete empty window produces the same valid envelope with zero roles. Compact UTF-8 JSON has fixed field order, newest first-seen first, ID-ascending ties, sorted field/state lists, and no trailing newline or BOM. No partial, top-N or fallback artifact is emitted.

Posting URLs are preserved exactly and deliberately use a conservative subset of the Worker's grammar. Only HTTP(S) with ASCII DNS names of at least two labels, alphabetic start to the final label, optional trailing dot and optional decimal port 1–65535. No credentials, IP literals, Unicode or Punycode hostnames. Path, query and fragment accept ASCII letters, digits, `._~!$&()*+,;=:@/?#-` and well-formed percent triplets. Raw spaces, apostrophes, braces, backslashes and Unicode URL text are outside the subset. An implicit root slash counts toward the 2,000-character limit. Encoded international paths, queries and fragments can be retained. Unsupported URL spelling fails the whole window. It never quietly removes a role or substitutes a zero-match artifact.

Synthetic Python tests cover the exact envelope, aliases, dates/offsets/leap and millisecond boundaries, duplicate/closed/oversized data, URL and display limits, and invalid catalog/shape. The optional offline probe passes Python-produced bytes over stdin to the exact #310 matcher at `c09cf2816fdbbd99082aaaddfb30d4874e694a12`, verifies matching and no-role scopes, and checks Python/Worker SHA-256 parity. Adding whitespace changes the pin even when matching is identical. The probe also rejects an independently mismatched upper bound and a coverage gap. The adjacent public-data tests and all producer checks pass (48 total with the probe enabled). Normal CI runs producer tests without depending on an unmerged Worker checkout.

For reproduction, set `INTERN_SCOUT_FOLLOW_MATCHER` to the local `worker/src/follow-matching.js` from the verified commit and run `python -m pytest backend/tests/test_follow_snapshot.py -q`. The Node probe loads only that local module and receives synthetic input. No outbound request or provider is used.

Production still needs an authoritative adapter after first-seen carry, explicit eligibility and URL normalization review, known timezone provenance and a precision decision for legacy exports. The adapter must prove complete coverage independently, including all expected shards and conflicting copies. The current tolerant listing reader cannot make that claim. Window duration, limits, freshness and recovery, public allowlist and immutable publication path remain separate decisions. Keep the exact bytes retrievable by timestamp and digest through the lifetime of pinned jobs, including rollover and publication lag. No build, export, taxonomy, configuration, public artifacts, golden files, sender or deployment changed.
