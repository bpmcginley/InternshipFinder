# 0.6.0 conservative resume factual anchors

Draft needs-bruce [#452](https://github.com/bpmcginley/InternshipFinder/pull/452), based on `ca660a4a85b19f226a0d567c402f5f357c1089ad`. This package adds local checks before profile/PDF/Word tailoring is rendered or cached. It does not change model, prompts, calls, review choices, guard, permissions, manifest, version or release behavior.

## Scope and limits

All three old validators accepted synthetic `Built a Python API` -> `Built a Kubernetes API` and `Helped 40 students` -> `Improved grades 40%`. The shared check now binds each numeric value to its explicit percent, percentage-point, currency or time unit (or unqualified number), and checks 18 distinct technical identifiers with narrowly defined spelling aliases. C#/.NET and SQL/Postgres are not treated as equivalent skills. Kubernetes/k8s is a true alias; its digit is not a new resume metric. Existing exact numeric spelling rules otherwise remain.

Bullets, entry paragraphs and projects use only their mapped original text. Another role, a skill elsewhere or the job description cannot supply an invented claim about that entry. Generated profile summaries use explicit experience/project/education/skill inputs, excluding goals, voice and unrelated metadata; existing PDF summaries may use the factual resume text. Unsupported replacements revert to the original, and unsupported new summaries are omitted. Existing formatting, protected Word runs, skills reorder, permitted bullet drop/order and review decisions remain intact.

This is deliberately not a general truthfulness classifier. It does not establish responsibility, causality, negation, ownership, or exhaustive technology coverage. `Kept lab records` -> `Led clinical trials` is still accepted, documented by a limitation test. Ordinary ambiguous words such as Go, R and Rust are not newly classified. A supported term's presence does not prove every assertion made about it. No semantic-model or paid evaluation is added.

Both real cache key paths now include the validation version: Word/PDF shared builder and profile-template builder. Old unchecked tailored files are not reused; the first subsequent request regenerates normally, while new checked hits still make zero model calls. Layout caching and the existing 12-entry cache retention policy are unchanged. No new storage or identifier is introduced. Human review controls and the existing explicit automatic/batch choices are byte-identical.

## Synthetic verification

- Read-only preflight on exact main: all 34 existing tailoring tests passed, despite the reproduced factual substitutions above.
- Final Node 22.23.4 extension suite: 365 tests pass, including nine new cases. The focused claims/flow pair passes all 17 cases. Scoped pinned ESLint, Prettier and startup reporting pass; Git whitespace check is clean.
- Cases cover swapped numeric-unit associations, distinct technical facts, positive aliases/paraphrases, all three formats, cross-entry and cross-posting contamination, summary evidence boundaries, allowed drop/order behavior, and cold/old-version/current-cache/new-posting behavior through all real tailoring paths.
- A local timing sample used 100 warmups and 1,000 iterations: one synthetic bullet p50 0.004 ms/p95 0.021 ms; summary against 100 synthetic source lines p50 0.546 ms/p95 1.374 ms. These are machine-local observations, not provider latency or performance guarantees. No additional AI call or token charge is introduced; invalidating an old cached file can require the next ordinary tailoring call.
- Guard source/tests, agent approval flow, manifest, Worker and Gemini/provider clients match the base. No public assets or golden fixture changed. No new UI strings or UI layout change; file-content behavior is exercised by synthetic render tests.

All data, files, model responses and URLs in tests are synthetic. No real profile, form, application, account, provider, production API, deployment or release was used. Independent exact-head review, green CI, post-refactor integration and coordinated 0.6.0 release qualification remain required.
