# P-2.1s dormant Worker archive reader

[Draft #330](https://github.com/bpmcginley/InternshipFinder/pull/330) is based on exact #310 `c09cf281`. The public archive contract is exact #327 `8290eced`; no Python code is merged into this Worker branch. This package has no production caller, route, scheduler, provider, sender, archive writer or public artifact changes. It remains needs-bruce.

`createFollowArchiveReader` requires an explicit HTTPS manifest URL at the candidate `/data/follows/index.json` path, injected GET transport and clock, catalog, matcher limits, and all archive bounds. There is no production origin, fetch or policy default. The digest-only blob path is constructed under the same origin and directory. Redirects and changed response URLs are rejected. Each operation owns its deadline timer, abort controller and stream reader. No response, request, promise or archive content is shared between operations. Only the last observed clock value is retained to fail closed on rollback; bounds and catalog are copied at construction.

The reader checks canonical v1 manifest bytes, exact key sets, safe integer lengths, strictly increasing UTC dates, unique digests, latest/high-water consistency and exact configured enqueue/retention arithmetic. Manifest bytes, entry count, individual snapshot bytes and the sum of declared archive bytes plus manifest are bounded. It never downloads every retained blob. The selected blob must match its exact size, SHA-256 and generation, compact producer JSON, complete coverage and existing matcher role/catalog validation. Duplicate JSON keys and partial/unknown-role data cannot silently become a valid complete snapshot.

`loadSnapshot({at, digest, maxBytes})` returns the exact `Uint8Array` or null. It is compatible with #298 preparation and retrieves an older retained pin independently of the latest snapshot's enqueue freshness. It requires the retained entry to exist and remain unexpired. `latest({effectiveLower})` returns `{status: "ready", at, digest, bytes}` only while fresh and covered; `{status: "gap"}` only for a lower watermark before the complete coverage; otherwise `{status: "unavailable"}`. It never skips a gap, advances a watermark or substitutes a different pin. Request and stream failures, stalled fetch/reads, clock rollback, absolute elapsed deadline or expiry return no bytes. Absolute clock checks supplement the abort timer, including before returning from asynchronous digest validation.

The fixture in `worker/test/fixtures/follow-archive-python.json` was generated locally by exact #327 Python `build_follow_snapshot` and `plan_follow_snapshot_archive`, using two synthetic UTC generations on 2028-01-01/02 at 23:59, a three-day complete window and a Unicode synthetic title. Synthetic bounds are 8,000 snapshot bytes, 10 roles, 2,000 text bytes, 24-hour enqueue age, 24-hour publication margin, five archive entries and 40,000 archive bytes. These are test inputs, not production policy. Its three inner files are the untouched canonical manifest and two immutable blobs. Independent reconstruction matched every byte.

Validation: 17 focused Node tests, the complete 449-test Worker Node suite on pinned Node 22.23.4, and all 69 actual local Workers-runtime tests passed, including two focused reader cases. Pinned Prettier, targeted ESLint and whitespace checks passed. Runtime tests exercise synthetic Response/crypto/deadline behavior and concurrent operations in one test runtime; they are not a production fetch or proof across separate deployed requests. Dependencies were installed from the offline cache. Windows ARM64 omitted the optional native workerd package; the existing matching 2026-09-11 executable supplied the local runtime, with no lockfile or shared checkout changes. Exact hosted checks remain required.

Independent review caught a delayed-timer edge before freezing: elapsed injected time could exceed the configured deadline before the timer callback ran. Operation-local absolute checks now reject after the first delayed read and before any next GET or returned result. The regression covers immediate synthetic responses at the exact elapsed boundary.

Owner decisions still cover origin, archive policy/bounds, catalog, publication/recovery, configuration and deployment. Raw inherited export timestamps are not interpreted here; the producer compatibility gate remains separate. No new public copy, user data, privacy policy, retention policy, secret, provider call or deployment is introduced.
