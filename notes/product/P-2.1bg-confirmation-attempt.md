# P-2.1bg Exact Follow confirmation attempt

This dormant package starts on #508 as merged at `a10f3053`. It qualifies one exact pending confirmation job through the existing mail renderer and an injected immediate transport. The trusted presentation receives the canonical scope and ephemeral capabilities. The database supplies the recipient directly to the renderer. The package selects no sender, origin, postal address or volume.

Presentation and rendering finish before either capacity or the job is spent. One D1 batch validates the original pending scope, recipient, creation and expiry, and absence of another live confirmation. It observes the existing shared ledger using a qualified SQLite UTC timestamp, conditionally claims the exact job, debits its winning claim and writes the three existing capability hashes. A full cap leaves that same job and its original expiry intact. A failed token insert rolls the transaction back. The standalone #508 claim keeps its existing behavior.

A fresh D1 read checks the same claim, pending scope, recipient, expiry, UTC day and three capabilities immediately before the one injected transport call. The Worker clock independently checks day, expiry and monotonicity, including after that last read. An unacknowledged or malformed transaction or final read authorizes no handoff. Once the transaction commits, the attempt remains spent even if later authorization becomes unavailable. A transport rejection or uncertain acknowledgement remains terminal. Any transport already initiated can finish after a concurrent deletion.

Synthetic Node and native Workers/D1 cases cover a full cap and same-job retry, competing shared attempts, render failure, consent and recipient changes during awaited work, transaction rollback, ambiguous acknowledgements, clock rollover and one transport call. Signup, account linkage, sender entitlement, action-link rollout, scheduling, privacy publication and deployment remain separate release gates.

Local Node 22 qualification passed the full Worker suite and all 407 native Workers/D1 tests. The new tests include five pure clock/readback cases and 15 native cases. Pinned ESLint and Prettier and Git whitespace checks passed.
