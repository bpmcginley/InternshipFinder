# P-2.1ch Follow management mail fragment

This package qualifies the exact management link approved in #542. Only the management body slot can render the canonical first-party capability link. Existing confirmation and request-deletion fragments and one-click unsubscribe headers keep their existing rules.

The reserved path and management links on the production site accept only `https://internscout.org/follows/manage.html#token=<management-token>` with one raw lowercase canonical token and an explicitly admitted origin. The renderer rejects query, duplicate, encoded or normalized spellings. Other private link slots cannot render this management route. The admitted management token cannot be repeated in an unsubscribe header or any other rendered link, including direct and similar-role posting URLs. Public links continue to reject embedded capabilities.

Synthetic non-fragment inputs on the older injected paths still qualify for dormant callers. This package adds no link issuance, public page, route, sender, transport or configuration. The exact production caller, page and provider readiness are separate rollout work.
