# P-2.1be Claim an exact pending Follow confirmation

[#508](https://github.com/bpmcginley/InternshipFinder/pull/508) builds on the pending queue from [#506](https://github.com/bpmcginley/InternshipFinder/pull/506). Migration 0022 adds one nullable opaque claim ID to each job. Existing jobs remain unclaimed. The ID stays on the job until the existing confirmation, scope replacement, deletion or expiry removes it.

The dormant helper accepts one exact job ID. A single D1 batch checks the database clock, original seven-day expiry, matching pending scope and absence of another live confirmation for that scope. It claims the job and writes the existing hash-only records for confirmation, scoped request deletion and address-wide unsubscribe. The latter is the distinct capability used by the renderer's unsubscribe header. The nonce is independent of all three credentials. The helper returns the raw values to its trusted caller only on an exact acknowledged claim with remaining lifetime. It does not return the subscriber's address.

A failed mutation rolls back the claim and all three credential writes. If a committed batch loses its acknowledgement, the job remains claimed and another invocation cannot recover or reissue its credentials. Repeated signup in that same scope lifetime still points to the claimed job. A deleted or expired scope can produce a new job with a new identity on a later explicit request.

Local Workers/D1 evidence covers populated migration and bootstrap parity, concurrent duplicate claims, a newer live confirmation, same-millisecond deletion and recreation, expired and future jobs, a final-write fault, a lost acknowledgement, and expiry before receipt. The existing confirmation, scoped deletion and address-wide unsubscribe handlers accept the issued credentials.

A future dispatcher must recheck the exact claim, current pending scope and matching live confirmation immediately before sending, and enforce the shared send cap. This package changes no signup or public route, linkage, sender, copy, transport, send budget or production migration.
