# P-4.4 static advisor weekly pages

Draft static-page package [#324](https://github.com/bpmcginley/InternshipFinder/pull/324), now stacked on reviewed #321 `50726047`. It remains needs-bruce; no publication has occurred.

The initial leaf claim was limited to new `backend/internscout/site/advisor.py`, `backend/internscout/site/render/advisor.py`, `backend/tests/test_site_advisor.py`, and this note. The lead subsequently cleared build.py, runtime.py, catalog.py, page_dates.py, the paired goldens, own STATUS/screens and the one existing thin-page test expectation. No asset/CSS, data, subscription or provider paths are changed.

The leaf selects an undergraduate major's direct fields from the existing mapping. Counts deduplicate matching exported roles, use bounded seven-day source timestamps, exclude future/closed/unsafe rows, and do not substitute other fields for an empty major. Missing source dates and unmapped majors have explicit neutral states. Existing major and field canonicals are preserved.

The renderer is static and forwardable. No subscription form, advisor tag, provider call, email, sender, cron, privacy change, storage or tracking is part of this slice. Advisor consent and provider configuration remain separate owner decisions. No deployment, merge or release is authorized here.

Freshness boundary tests, selection/render tests and exact integration/evidence results will be recorded before review. Current shared-output evidence remains unchanged until integration is explicitly cleared.

## Historical leaf evidence

Baseline: 145 existing digest/page tests passed before the new modules. After the URL/copy review: 42 focused cases and all 187 combined tests passed; Python lint has zero errors/warnings. The source is not wired into the build, so no existing output or golden artifact changes. Posting links reject any userinfo (including an empty username), ASCII/C1 controls, backslashes, and invalid or empty ports; ordinary HTTP(S) links and valid ports remain accepted. Empty valid windows state the zero count once, followed only by older-role guidance.

The selection window is `(export timestamp - 7 days, export timestamp]` in UTC. Validated first-seen timestamps are required. Future posting timestamps, malformed supplied posting timestamps, postings at least 14 days old, bootstrap/baseline rows, closed rows and unsafe URLs are omitted. Filtering direct fields precedes the existing employer/title/location deduplication, so an unrelated duplicate cannot remove a matching role. Related fields never fill a gap. No data leaves the local process.

A read-only check of the checked-in export `2026-11-11T05:15:00.914089+00:00` produced 78 mapped, nonempty undergraduate editions and two unmapped states. Every selected ID was unique within its edition and every row satisfied the exact time bounds. These are source-data checks, not traffic, employer eligibility or delivery evidence. Current models default to noindex until shared discovery integration is reviewed. Parent links use the actual supplied canonical major mapping and otherwise point to the majors hub.
