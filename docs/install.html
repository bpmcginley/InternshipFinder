Install the extension

About a minute · Chrome, Edge or Brave on a laptop or desktop

This one needs a laptop

Chrome, Edge and Brave on phones and tablets can't add extensions from the Chrome Web Store, so the steps below won't work here. Send yourself the link and open it on your laptop. Searching still works on this phone: the dashboard needs no extension and no account.

InternScout Auto-Apply is in the Chrome Web Store. Add it in a click, and it keeps itself up to date.

You don't need the extension to search. The dashboard works on its own. The extension adds your Deep Dive profile and Auto-Apply, which fills out applications and stops at the submit button.

  1. Add it from the Chrome Web Store

    Open the listing, click Add to Chrome, then Add extension. The Deep Dive setup opens in a new tab.

    Edge: click Allow extensions from other stores in the bar at the top of the listing first, then add it the same way. Brave works like Chrome.

    Open it in the Chrome Web Store

  2. Pin it to your toolbar

    Click the puzzle-piece icon next to the address bar, then the pin next to InternScout Auto-Apply.

  3. Sign in with Google or Microsoft

    Click the InternScout icon and choose Sign in with Google (UMass email) or Sign in with Microsoft. Any Google account or personal Microsoft account works. A Google account with a .edu email gets twice the monthly AI use. We never see your password.

    School Microsoft accounts (like your @umass.edu Outlook login) don't work yet: they ask for your school's IT approval. To get the higher .edu allowance, sign in with Google using your @umass.edu address. If you don't have one, create a Google account with Use your existing email and enter your @umass.edu email.

    Sign-in is only needed for AI features like Auto-Apply and tailored resumes.

    Every account gets a free AI allowance each month. If you use it up, Supporter ($5/month) or Pro ($12/month) raises it; both are optional, and Stripe handles the payment and the cancelling. Searching, ranking and the dashboard stay free and need no account at all.

Next

  • Finish the Deep Dive: your resume, facts and a few short questions. Everything stays on your device.
  • Open the dashboard, tick some listings and press Auto-Apply.
  • Most applications run on a system the extension already has access to. When one is on an employer's own careers site, the job pauses and the side panel shows an Allow that site button. Chrome then asks about that one site. Nothing else is granted, and you can say no.
  • If it helps you, a rating on the Web Store listing helps other students find it.

Installed it by hand before?

The Web Store version is a separate extension from the one you loaded by hand, so nothing you saved in the old copy carries over. Before you switch:

  • Keep your own copy of your resume and any files you uploaded.
  • Save the passwords for employer accounts it created in your password manager. They're under Accounts in the side panel, with a Copy button.

Then add the Web Store version, sign in and redo the Deep Dive. Once it works, remove the old copy at chrome://extensions (it's the InternScout card with a reload arrow), so the two don't both try to fill the same application. Your dashboard profile and application statuses are kept, because the dashboard saves them in your browser, separately from the extension.

Updating

Nothing to do. Chrome updates Web Store extensions on its own, usually within a few hours of a new version.

Troubleshooting

  • No "Add to Chrome" button: the store only offers it in desktop Chrome, Edge and Brave. On a school- or work-managed computer your IT department may block extensions; use your own laptop instead.
  • Sign-in fails: try the other provider, or check that pop-ups aren't blocked. If you expected the larger school allowance, sign in with the account that has your .edu email. If it still fails, open an issue.
  • Remove it: go to chrome://extensions and click Remove. Chrome deletes everything the extension saved. See how to delete your data.

Install by hand instead

Only if the Web Store route doesn't work for you. The by-hand copy doesn't update itself.

Installed by hand before September 22, 2026? That copy (0.4.2 or older) only works with the old bpmcginley.github.io address, so it no longer connects to the dashboard. Remove it at chrome://extensions and add InternScout from the Chrome Web Store (or load 0.4.3 or newer by hand). Your dashboard profile and saved statuses from the old address don't carry over to internscout.org, so set your profile up again there.

  1. Open the latest release on GitHub. Under Assets, download internscout-extension-version.zip. Don't pick "Source code".
  2. Unzip it into a folder you'll keep, like Documents. Windows: right-click the zip, then Extract All. Mac: double-click the zip. Chrome runs the extension from this folder, so if you delete or move it, the extension stops working.
  3. Type chrome://extensions in the address bar and press Enter. In Edge, use edge://extensions. (Browsers don't let you click these links, so type it.)
  4. Flip the Developer mode switch. In Chrome it's at the top right. In Edge it's in the left sidebar.
  5. Click Load unpacked and pick the folder you unzipped: the one with manifest.json directly inside. If Chrome says "Manifest file is missing or unreadable", you picked the outer folder.
  6. Pin it and sign in, as in steps 2 and 3 above.

Updating a by-hand copy: download the new zip, replace the files in your existing folder (keep it in the same place), then click the reload arrow on the InternScout card at chrome://extensions. Your profile and files are saved in Chrome, not in the folder, so they carry over.

Chrome may show a "Disable developer mode extensions" warning for extensions installed by hand. It's normal; close it to keep using InternScout.
