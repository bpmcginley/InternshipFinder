Install the extension

About 3 minutes · Chrome, Edge or Brave on a laptop or desktop

This one needs a laptop

Chrome, Edge and Brave on phones and tablets can't load an extension from a folder, so the steps below won't work here. Send yourself the link and open it on your laptop. Searching still works on this phone: the dashboard needs no extension and no account.

The InternScout Auto-Apply extension isn't in the Chrome Web Store yet. Until it is, you install it by hand. These steps show you how.

You don't need the extension to search. The dashboard works on its own. The extension adds your Deep Dive profile and Auto-Apply, which fills out applications and stops at the submit button.

  1. Download the zip

    Open the latest release on GitHub. Under Assets, download internscout-extension-version.zip. Don't pick "Source code".

    Open the latest release

  2. Unzip it into a folder you'll keep

    Windows: right-click the zip, then Extract All. Mac: double-click the zip.

    Move the new folder somewhere it can stay, like Documents. Chrome runs the extension from this folder. If you delete or move it, the extension stops working.

  3. Open the extensions page

    Type chrome://extensions in the address bar and press Enter. In Edge, use edge://extensions. (Browsers don't let you click these links, so type it.)

  4. Turn on Developer mode

    Flip the Developer mode switch. In Chrome it's at the top right. In Edge it's in the left sidebar.

  5. Click Load unpacked

    Pick the folder you unzipped: the one with manifest.json directly inside. An InternScout Auto-Apply card appears, and the Deep Dive setup opens in a new tab.

  6. Pin it to your toolbar

    Click the puzzle-piece icon next to the address bar, then the pin next to InternScout Auto-Apply.

  7. Sign in with Google or Microsoft

    Click the InternScout icon and choose Sign in with Google (UMass email) or Sign in with Microsoft. Any Google account or personal Microsoft account works. A Google account with a .edu email gets twice the monthly AI use. We never see your password.

    School Microsoft accounts (like your @umass.edu Outlook login) don't work yet: they ask for your school's IT approval. To get the higher .edu allowance, sign in with Google using your @umass.edu address. If you don't have one, create a Google account with Use your existing email and enter your @umass.edu email.

    Sign-in is only needed for AI features like Auto-Apply and tailored resumes.

    Every account gets a free AI allowance each month. If you use it up, Supporter ($5/month) or Pro ($12/month) raises it; both are optional, and Stripe handles the payment and the cancelling. Searching, ranking and the dashboard stay free and need no account at all.

Next

  • Finish the Deep Dive: your resume, facts and a few short questions. Everything stays on your device.
  • Open the dashboard, tick some listings and press Auto-Apply.
  • Most applications run on a system the extension already has access to. When one is on an employer's own careers site, the job pauses and the side panel shows an Allow that site button. Chrome then asks about that one site. Nothing else is granted, and you can say no.

"Disable developer mode extensions" warning

Chrome may show this warning for extensions installed by hand. It's normal. Close it to keep using InternScout. It goes away once the extension is in the Web Store.

Switching to the Web Store version later

The Web Store version is a separate extension from this one, so nothing you saved here carries over to it. Before you switch:

  • Keep your own copy of your resume and any files you uploaded.
  • Save the passwords for employer accounts it created in your password manager. They're under Accounts in the side panel, with a Copy button.

Then add the Web Store version, sign in and redo the Deep Dive. Once it works, remove this copy at chrome://extensions, so the two don't both try to fill the same application. Your dashboard profile and application statuses are kept, because the dashboard saves them in your browser, separately from the extension.

Updating

  1. Download the new zip from the latest release.
  2. Unzip it and replace the files in your existing folder. Keep the folder in the same place.
  3. Go to chrome://extensions and click the reload arrow on the InternScout card.

Your profile and files are saved in Chrome, not in the folder, so they carry over. If you load the extension from a different folder location, Chrome treats it as a new extension and your saved profile won't show up.

Troubleshooting

  • "Manifest file is missing or unreadable": you picked the outer folder. Open it and pick the folder that has manifest.json inside.
  • Sign-in fails: try the other provider, or check that pop-ups aren't blocked. If you expected the larger school allowance, sign in with the account that has your .edu email. If it still fails, open an issue.
  • Remove it: go to chrome://extensions and click Remove. Chrome deletes everything the extension saved. See how to delete your data.
